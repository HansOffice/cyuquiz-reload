CyuQuiz-Reload 使用文档

CyuQuiz-Reload 用来在服务器里定时出题、全服抢答、排行榜统计、连对奖励和定时答题活动

支持单选、多选、问答填空与声音线索辨听，自带奖池滚存、名次阶梯奖励、全服狂热时刻与段位系统

定时出题抢答 多文件独立题库 原版音效辨听 奖池滚存累加 阶梯名次领奖 中英双语提示

安装

放入插件

按服务端类型选择对应 jar，放进服务器的 plugins 文件夹

启动一次

第一次启动会生成主配置、语言文件、题库目录与数据文件，生成后按需微调配置

设置权限

普通玩家默认拥有 cyuquiz.use，管理与活动命令按需分配给 OP

进服测试

执行 /cyuquiz bank list，能看到已加载题库后，即可正常参与答题

选择哪个 jar

文件 适合场景
cyuquiz-reload-paper-1.0.4.jar 1.21 起的 Paper / Spigot / Purpur 服务端
cyuquiz-reload-folia-1.0.4.jar 1.21 起的 Folia 服务端
cyuquiz-reload-legacy-1.0.4.jar 1.16.5 到 1.20 的 Spigot / Paper 老服
三个 jar 只放一个；当前文档对应 1.0.4；功能完全一致，根据服务端环境选择对应 jar 即可

生成的主要文件

文件 / 目录 负责什么 常改哪里
config.yml 核心规则、出题间隔、玩法开关、防脚本参数与视觉设置 出题间隔、滚存奖池金额、阶梯名次比例、狂热时刻门槛
quizzes/ 多文件独立题库目录 按需添加或修改 .yml 题库文件，增删题目
stats.yml 本地玩家答题与连对数据 未开启 MySQL 时自动记录，通常无需手动修改
lang/zh_cn.yml、lang/en_us.yml 玩家看到的提示信息与帮助手册，中英文各一份 提示前缀、报错文案；用 config.yml 里的 language 切换
backup/ 配置更新备份目录 覆盖前自动保留旧版配置，用于比对自定义修改

第一次上线

配置调整完毕后，建议按下面的顺序检查一遍功能状态

/cyuquiz bank list
/cyuquiz help
/cyuquiz stats
/cyuquiz top
/cyuquiz reload
命令 看什么
/cyuquiz bank list 确认五个默认题库已成功读取，题目总数统计正常
/cyuquiz help 确认分页帮助正常弹出，点击条目可回填指令
/cyuquiz stats 确认个人作答统计能够正常查询
/cyuquiz top 确认排行榜能正常渲染格式与标题
/cyuquiz reload 确认重载配置与题库无报错，提示重载成功
正式服更新配置或增删题库后，执行 /cyuquiz reload 即可热生效，无需重启服务端

权限

普通玩家默认拥有基础作答与查询权限，管理命令默认仅授予 OP

权限 说明 默认
cyuquiz.use 查看帮助、个人统计、排行榜、题库列表与提交答案 玩家
cyuquiz.reload 重载插件配置与所有题库 OP
cyuquiz.event.admin 查看活动状态、开启或终止定时答题活动 OP

题库配置

题库采用多文件目录设计，放在 plugins/cyuquiz-reload/quizzes/ 目录下；每个 .yml 对应一个独立题库，删除或新增文件不影响其他题库

minecraft.yml

原版机制、合成配方与红石常识题库，适合所有生存服务器直接使用

sound_clues.yml

声音侦探题库，出题时同步播放原版音效，玩家听声音辨识目标生物或事件

dimensions.yml

异界探秘题库，包含下界群系、遗迹结构与末地机制进阶常识

safety.yml

防骗与服务器安全守则，通过答题普及账号安全与基础服规

general.yml

百科常识题库，涵盖自然科技与生活趣味知识，活跃服内日常闲聊

题库配置写法

name: "原版生存"              # 题库在聊天栏与列表里显示的名称
enabled: true                 # 是否启用这个题库
weight: 50                    # 随机出题时的抽取权重，数值越大抽中概率越高
worlds: []                    # 限制在哪些世界出题，留空表示全服所有世界都出

questions:
  - id: mc_torch              # 题目唯一 ID，同一题库内不能重复
    text: "合成火把的配方是？"    # 题目文本
    type: single              # 题型：single 单选 / multiple 多选 / input 问答
    options:                  # 候选选项，键名用单个大写字母
      A: "煤炭加木棍"
      B: "铁锭加木棍"
      C: "打火石加木板"
      D: "红石加木棍"
    answer:                   # 正确答案
      - A
    difficulty: easy          # 题目难度，需在 config.yml 的 difficulties 里配过
    messages:
      question: "📝 &b{bank_name}&f · {difficulty} &b{player_name}&f，请回答：&9{quiz_id}&f → {question}"
      on-correct: "✅ &a恭喜 &b{player_name}&f，答对了！正确答案：&9{correct_option}&f 🎉"
      on-wrong: "❌ &c抱歉 &b{player_name}&f，答案 &9{option}&f 错误！"
    rewards:                  # 答对奖励指令列表
      - "console:money give {player_name} 500"
      - "console:exp give {player_name} 10"
旧版平滑迁移：如果从旧版升级并留有 quizzes.yml，插件初次加载时会自动将原题目导入 quizzes/legacy.yml，不会丢失自定义题目

题型与声音线索

支持三种交互题型，并支持为题目绑定原版音效制作听力抢答

题型 怎么作答 编写要求
single（单选） 聊天栏输出带悬浮提示的选项按钮，玩家直接鼠标点击或在聊天框输入对应字母 options 至少配两个选项，answer 填一个正确字母
multiple（多选） 聊天框列出选项，玩家在聊天栏输入多个选项字母（如 A,C 或空格隔开） answer 填写所有正确选项，全部答对才算正确
input（问答填空） 问答题无需选项，玩家直接在聊天栏输入关键词文本 options 留空，answer 可填多个允许的答案关键词

原版声音线索

在题目节点加上 sound-clue: 音效名，出题时会自动向接收题目的玩家播放指定声音，打造听声辨位抢答

  - id: snd_creeper_fuse
    text: "仔细听正在播放的声音线索，这是什么声音？"
    type: single
    sound-clue: ENTITY_CREEPER_PRIMED
    options:
      A: "苦力怕即将自爆的引线声"
      B: "营火烤肉的滋滋声"
      C: "下界传送门启动声"
    answer:
      - A
    difficulty: easy

互动玩法

内置滚存奖池、阶梯领奖、狂热时刻与段位进阶，丰富日常答题体感

奖池滚存累加

题目到时间无人答对时，奖池倍率自动 +1 并累加金币奖金；下一道题首位答对的玩家独揽滚存大奖，全服通告

前三名阶梯领奖

单题支持多人获奖，第一名拿全额 100%，第二名拿 60%，第三名拿 30%，避免单人秒答打击全服热情

全服狂热时刻

全服累计答对达到指定题数后进入狂热时刻，屏幕弹出大标题通告，出题频率临时加速且全部奖励自动翻倍

答题段位称号

累计答对题数自动晋升段位称号（童生、秀才、举人、进士、探花、榜眼、状元），配合变量展示在聊天或头顶

出题智能休眠

全服在线人数低于 pacing.min-players 时，出题计时器自动暂停，防止深夜无人在线空跑题目与奖池

防脚本设置

多重防护机制，有效拦截预录宏、秒答脚本与多开小号

防护机制 体感表现 对应配置
最快作答门槛 出题后答题用时少于 800ms 直接拦截并提示太快，防止脚本秒答 anti-bot.min-reaction-ms: 800
动态选项令牌 出题时生成临时点击令牌，点击按钮提交令牌验证，防止玩家录制固定指令连点 anti-bot.dynamic-token: true
同 IP 作答配额 同一 IP 每道题只允许一人提交，防止单人多开小号矩阵式穷举 anti-bot.max-answers-per-ip: 1
连续答错冷却 连续答错 3 次自动禁言暂停作答 30 秒，防止乱点穷举爆破 anti-bot.wrong-answer-penalty-seconds: 30
最低游戏时长 需要在线游玩达到指定分钟数才允许参与作答，防止刚建小号刷金币 anti-bot.min-playtime-minutes: 0

定时答题活动

适合晚间集体活动或周末专场竞赛，支持自动定时开启与手动控制

events:
  evening:
    enabled: true                   # 是否启用这个活动
    name: "晚间知识大冲关"            # 活动名称
    worlds: ["world"]               # 生效世界
    start-time: "19:00"             # 每天开始时间（24小时制 HH:mm）
    end-time: "19:30"               # 每天结束时间
    question-count: 15              # 本场最多出题数量
    question-interval-seconds: 60   # 每道题间隔秒数
    answer-seconds: 45              # 每题有效作答时间
    pool:
      banks: ["minecraft"]          # 限定抽取的题库列表
      difficulties:
        easy: 5
        normal: 7
        hard: 3
    rewards:
      participation:                # 阳光普照参与奖
        - "console:money give {player_name} 100"
      top:                          # 积分排名前三名奖励
        1:
          - "console:give {player_name} diamond 5"
        2:
          - "console:give {player_name} diamond 3"
        3:
          - "console:give {player_name} diamond 1"

数据存储

玩家总答题、答对、答错、最高连对与当前连对支持本地文件或 MySQL 双模式

存储方式 配置方法 适用场景
本地文件 (YAML) database.use-mysql: false 单端或轻量服务器，数据直接存在 stats.yml，备份转移简单
MySQL 数据库 database.use-mysql: true 并填写 database.uri 多端互通或大服网络，自动创建 cyuquiz_stats 数据表并异步保存

PlaceholderAPI

安装 PlaceholderAPI 后可用以下变量，可在计分板、聊天格式与菜单里直接引用

占位符变量 说明与返回值示例
%cyuquiz_answered% 玩家总作答题目数量，如 120
%cyuquiz_correct% 玩家答对题目总数，如 90
%cyuquiz_wrong% 玩家答错题目总数，如 30
%cyuquiz_current_streak% 玩家当前连续答对数量，如 5
%cyuquiz_highest_streak% 玩家历史最高连续答对数量，如 12
%cyuquiz_accuracy% 玩家答题正确率百分比，如 75.0%
%cyuquiz_rank% 玩家当前段位称号，如 §b[举人]
%cyuquiz_rank_next% 晋级下一段位所需答对题数，满级返回 MAX
%cyuquiz_jackpot% 当前奖池累积倍率，如 3
%cyuquiz_fever% 当前是否处于狂热时刻，返回 是 或 否

开发 API

其他插件需要联动或监听问答事件时，直接使用门面与事件，无需自行解析题库

val api = CyuQuizProvider.api
val current = api.getCurrentQuestion()
val stats = api.getPlayerStats(player.uniqueId)

// 支持监听题目下发与玩家作答事件
@EventHandler
fun onBroadcast(event: QuizQuestionBroadcastEvent) {
    val q = event.question
}

@EventHandler
fun onAnswer(event: QuizPlayerAnswerEvent) {
    val isRight = event.isCorrect
}

命令

主指令为 /cyuquiz，别名包含 /quiz 与 /cquiz，支持 Tab 补全与权限过滤

命令 权限 用途
/cyuquiz help [页码] 全体 查看分页帮助手册，条目可点击回填命令
/cyuquiz answer <答案> cyuquiz.use 回答当前题目
/cyuquiz stats cyuquiz.use 查看个人作答统计与最高连对
/cyuquiz top cyuquiz.use 查看全服答题正确数 Top 10 排行榜
/cyuquiz bank list cyuquiz.use 查看所有题库的启用状态与题目数量统计
/cyuquiz reload cyuquiz.reload 热重载配置、语言文件与题库
/cyuquiz event list cyuquiz.event.admin 查看配置好的活动列表
/cyuquiz event status cyuquiz.event.admin 查看当前正在进行的活动进度与参与人数
/cyuquiz event start <活动ID> cyuquiz.event.admin 手动开启指定答题活动
/cyuquiz event stop cyuquiz.event.admin 手动终止当前正在进行的答题活动

常见问题

聊天框输入答案为什么没有反应

检查当前世界是否在 world-filter 中被屏蔽；多选题需同时输入所有正确选项；确认是否有聊天格式插件拦截了聊天事件

玩家提示作答速度过快

防脚本机制生效，玩家作答用时短于 anti-bot.min-reaction-ms（默认 800ms）会被判定为秒答宏；若服内网络延迟极低导致误触，可微调为 500ms

修改题目后如何立即生效

在 quizzes/ 目录下编辑或新增 .yml 题库文件后，输入 /cyuquiz reload 即可热重载，无需重启服务器

如何完全关闭定时活动只保留日常出题

在 config.yml 中把对应活动下的 enabled 改为 false 即可

更换服务端核心数据会丢失吗

不会；Paper、Folia 与 Legacy 运行包共享完全一致的配置文件和数据格式，跨版本升级时数据无缝兼容

配置建议

  1. 用默认配置启动一次服务端，生成文件
  2. 给默认玩家组 cyuquiz.use 权限，给管理员 cyuquiz.reload 与 cyuquiz.event.admin
  3. 执行 /cyuquiz bank list 确认五个预设题库读取正常
  4. 按服务器定位在 config.yml 中微调出题间隔，推荐设为 1200 到 1800 秒
  5. 将 pacing.min-players 设为 2 到 3，避免深夜无人在线空跑题目
  6. 如果需要定时竞赛，开启 events.evening 并设置适合的晚间活动时段
  7. 用测试号走一遍点击作答、错误冷却与排行榜查询，确认无误后再正式开放
