CyuQuiz-Reload 使用文档

CyuQuiz-Reload 是新一代互动问答与定时答题插件，支持多文件独立题库目录、世界空间感知分发、原版音效线索题、奖池滚存累加、前三名阶梯领奖、答题荣誉段位、全服狂热时刻与五重防脚本秒答拦截。

专为 Paper / Folia / Legacy 三端物理分流打造，提供敏感级并发安全调度与黑盒级服主运维体验。

多文件独立题库奖池滚存与狂热五重防脚本荣誉段位体系

安装与升级

步骤说明
放置插件根据服务端类型选择 cyuquiz-reload-{paper|folia|legacy}-1.0.4.jar 放入服务器 plugins 目录
首次启动重启服务器自动生成 config.yml、lang/ 多语言目录及 quizzes/ 题库目录
平滑升级内建配置升级管理器，自动继承历史参数并生成完整快照至 backup/ 目录
旧版题库兼容若检测到旧版根目录 quizzes.yml，插件将在首次启动时自动归档迁移为 quizzes/legacy.yml

多文件题库系统 (quizzes/)

每个 quizzes/*.yml 文件代表一个独立题库，文件名即为题库唯一标识（如 minecraft.yml 对应 minecraft）。

name: "原版常识"
enabled: true
weight: 50
worlds: []
questions:
  - id: mc_torch
    text: "合成火把的配方？"
    type: single
    options:
      A: "一个煤炭一个木棍"
      B: "一个铁锭一个木棍"
    answer:
      - A
    difficulty: easy
    rewards:
      - "console:money give {player_name} 500"
字段说明
name题库显示名称，用于广播与占位符 {bank_name}
weight题库轮播抽取权重，设为 0 时不参与日常轮播，仅供专属活动抽取
worlds题库限定生效世界，留空表示继承全局设置；指定后仅在对应世界出题与广播
sound-clue可选音效线索题，出题时向玩家客户端播发指定原版音效（如 ENTITY_CREEPER_PRIMED）

特色玩法机制

机制玩法表现服主价值
奖池滚存 (Jackpot)题目时间到无人答对时，倍率自动滚存到下一题（最高可达 5 倍）彻底消除无人答题时的冷场挫败感，极大刺激抢答查资料欲望
阶梯领奖 (Tiered)前 3 名答对玩家均可获奖（如第一名 100%，第二名 60%，第三名 30%）保护手慢半秒的玩家体验，让非键盘快手也能享受到答题乐趣
狂热时刻 (Fever)全服累计答对达标后进入狂热时间，出题间隔加快至 30 秒且全员双倍奖励将单人答题转化为全服合力的社交高潮时刻
段位荣誉 (Ranks)累计答对题数自动晋升童生、秀才、进士直至状元，支持 PAPI 称号展示提供长线沉淀与荣誉追求，适合绑定聊天称号或计分板
智能休眠 (Pacing)全服在线玩家低于门槛时自动暂停出题计时，不刷屏、不空跑消耗 CPU杜绝深夜无人时日志狂刷，敏感级性能无额外资源浪费

防脚本与防刷题安全

防御防线运作原理
人类生理反应拦截作答时间低于 min-reaction-ms（默认 800ms）判定为外部脚本秒答并拦截
动态作答令牌聊天栏按钮每次出题生成一次性随机 Token（如 /cyuquiz answer tk_a8f9x），阻断固定宏嗅探
同 IP 并发限制单道题目限制同一 IP 的作答玩家数量（默认 1），阻断小号多开刷题
连错阶梯惩罚连续答错达到阈值自动进入惩罚冷却期（默认禁答 30 秒），阻断穷举暴力试探
在线时长资格门槛可配置新玩家最低游戏在线分钟数，阻断批量注册小号刷金币

定时活动场次

events 用于配置每天固定时间开启的专题答题活动，活动期间暂停日常普通出题，结束后恢复。

events:
  evening:
    enabled: true
    name: "晚间答题"
    start-time: "19:00"
    end-time: "19:30"
    question-count: 15
    question-interval-seconds: 60
    answer-seconds: 45
    pool:
      banks:
        - "minecraft"
      difficulties:
        easy: 5
        normal: 7
        hard: 3

命令与权限

命令权限说明
/cyuquiz help [页码]按权限显示查看系统帮助（支持点击回填）
/cyuquiz answer <答案>cyuquiz.use回答当前题目（支持 250ms 点击防抖）
/cyuquiz statscyuquiz.use查看个人答题统计
/cyuquiz topcyuquiz.use查看答题排行榜 Top 10
/cyuquiz bank listcyuquiz.use查看所有已加载题库与题目统计
/cyuquiz reloadcyuquiz.reload重载配置文件、多语言与全部题库
/cyuquiz event listcyuquiz.event.admin查看所有配置的活动标识
/cyuquiz event statuscyuquiz.event.admin查看当前活动进行状态
/cyuquiz event start <活动ID>cyuquiz.event.admin手动开启指定活动
/cyuquiz event stopcyuquiz.event.admin手动终止当前活动

PlaceholderAPI 变量支持

占位符说明
%cyuquiz_answered%玩家总答题数量
%cyuquiz_correct%玩家答对的题目数量
%cyuquiz_wrong%玩家答错的题目数量
%cyuquiz_current_streak%玩家当前连对题目数量
%cyuquiz_highest_streak%玩家最高连对题目数量
%cyuquiz_accuracy%玩家答题正确率百分比（如 85.5%）
%cyuquiz_rank%玩家当前答题荣誉段位称号（如 [进士]）
%cyuquiz_rank_next%晋升下一段位所需答对题数（最高段位显示 MAX）
%cyuquiz_jackpot%当前滚存奖池倍率（如 3）
%cyuquiz_fever%全服当前是否处于狂热时刻（是/否）

运维建议

推荐采用多世界题库隔离策略：在生存服出原版百科，在副本服出 Lore 题目。开启奖池滚存与阶梯奖励后，建议配合防脚本动态令牌，既保证公平竞技，又将全服参与度最大化。
